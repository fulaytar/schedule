# Розклад на тиждень

Сайт із тижневим розкладом. Відкривається з телефона, планшета, ноутбука чи комп'ютера.
Переглядати можуть усі, хто має посилання. Змінювати — лише з паролем.

- **Тиждень** — повна сітка (на комп'ютері відкривається сама).
- **День** — список на один день (на телефоні й планшеті відкривається сам).
- **Зараз / Далі** — що йде зараз і що буде наступним.
- **Статистика за місяць** — години роботи, уроки, заняття, тренування.
- Світла й темна тема (кнопка з місяцем / сонцем).

---

## 1. Викласти на GitHub (один раз)

1. На github.com створи **новий репозиторій** з назвою `schedule`, тип **Public**.
   (Безкоштовні GitHub Pages працюють тільки з публічними репозиторіями.)
2. Завантаж туди вміст цієї папки — через GitHub Desktop або командами:
   ```bash
   git init
   git add .
   git commit -m "Розклад"
   git branch -M main
   git remote add origin https://github.com/ТВІЙ_ЛОГІН/schedule.git
   git push -u origin main
   ```
3. У репозиторії: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Відкрий вкладку **Actions** і дочекайся зеленої галочки (1–2 хв).
5. Сайт буде тут: **`https://ТВІЙ_ЛОГІН.github.io/schedule/`**

На телефоні відкрий сайт і додай на головний екран (Safari: «Поділитися → На початковий екран»,
Chrome: «⋮ → Додати на головний екран») — відкриватиметься як застосунок.

## 2. Увімкнути редагування за паролем (один раз)

Сайт зберігає зміни прямо в репозиторій. Для цього йому потрібен GitHub-токен,
а токен зашифрований твоїм паролем.

**а) Створи токен**

1. github.com → аватар → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. **Token name:** `rozklad-site`. **Expiration:** наприклад, 1 рік.
3. **Repository access:** *Only select repositories* → `schedule`.
4. **Permissions → Repository permissions → Contents: Read and write**. Більше нічого не вмикай.
5. **Generate token** і скопіюй його (він показується лише один раз).

**б) Зашифруй токен паролем** — у папці проєкту (потрібен [Node.js](https://nodejs.org) 20+):

```bash
npm install
npm run secret
```

Скрипт спитає логін, назву репозиторію, токен і пароль (щонайменше 8 символів).
Якщо пароль простий, скрипт попередить і спитає, чи використати його все одно.
З'явиться файл `public/data/secret.json`.

**в) Закоміть і запуш** `public/data/secret.json`. Через хвилину на сайті запрацює кнопка **«Змінити»**.

## 3. Як змінювати розклад

1. На сайті натисни **«Змінити»** (замок) і введи пароль.
2. Натискай на клітинки: вибери вид заняття, назву, за потреби — точний час (напр. 20:30).
3. Унизу з'явиться панель — **«Зберегти»**.
4. На інших пристроях зміни з'являться за 1–2 хвилини (поки GitHub пересобирає сайт).

Через 30 хвилин без дій редагування саме вимикається.

## Безпека — коротко

- Токен лежить у репозиторії **лише в зашифрованому вигляді** (AES-256-GCM, ключ із пароля через PBKDF2, 600 000 ітерацій).
  Без пароля з нього нічого не витягнути — тому пароль має бути довгим і ніде більше не використовуватися.
- Після введення пароля токен живе тільки в пам'яті вкладки; після закриття вкладки зникає.
- Токен може змінювати **тільки цей один репозиторій** і нічого більше.
- Якщо пароль міг хтось дізнатися: на GitHub видали токен (**Settings → Developer settings → … → Delete**),
  створи новий і знову запусти `npm run secret` з новим паролем.
- Забув пароль — просто ще раз `npm run secret` (можна з тим самим токеном).
- Репозиторій публічний, тож **розклад бачить кожен, хто знайде посилання**, включно з іменами учнів.
  Якщо це небажано — пиши в розкладі ініціали.

## Структура

```
public/data/schedule.json   ← сам розклад (дані)
public/data/secret.json     ← зашифрований токен (створює npm run secret)
scripts/make-secret.mjs     ← скрипт шифрування
src/
  App.tsx                   ← складає сторінку з компонентів
  components/               ← Header, NowCard, WeekGrid, DayView, Legend,
                              CellEditor, UnlockDialog, SaveBar, Toast, Footer
  components/stats/         ← MonthStats, StatTile, CategoryBars, WeekdayBars
  hooks/                    ← useSchedule, useEditor, useNow, useTheme, useMediaQuery
  lib/                      ← час, злиття блоків, статистика, шифрування, GitHub API
.github/workflows/deploy.yml ← автозбирання й публікація на GitHub Pages
```

Локальний запуск для розробки: `npm install`, потім `npm run dev`.
